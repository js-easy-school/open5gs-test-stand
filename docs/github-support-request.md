# Обращение в поддержку GitHub (снять блокировку Actions)

Отправлять здесь: https://support.github.com/request → категория **Billing**.
Ниже готовый текст, менять ничего не нужно — только вставить.

---

**Subject:** Actions locked due to billing issue — unpaid invoices with a card that can no longer be authorized

Hello,

My account `js-easy-school` is locked for GitHub Actions with the message:
"The job was not started because your account is locked due to a billing issue."

Payment history shows three declined charges of $14.00 (2026-01-19 and 2026-01-25).
The card on file could not be authorized any more, so the payments failed. I have now
removed that payment method from my account, and I am not able to add a working one:
cards issued in my country are not accepted by the payment processor.

I currently have no paid subscriptions — my account is on GitHub Free with Copilot Free,
and I do not intend to use paid features. I would like to ask you to write off the
outstanding balance and unlock GitHub Actions for my account, so that I can run CI
workflows in my public repositories, which are free of charge.

If cancelling the outstanding invoices is not possible, please tell me what options exist
to settle the balance without a credit card.

Thank you.

---

## Что учесть

- Ответ обычно приходит за 1–3 рабочих дня.
- Просить именно **write off / cancel the outstanding balance** — оплатить российской картой всё равно не выйдет.
- Не заводить в переписке разговоров о том, чтобы обойти оплату иными путями: просьба корректная, услугами вы не пользуетесь.
- Пока ответа нет, CI можно держать в другом аккаунте — код в этом репозитории от этого не меняется.
